# Spectral Clustering With Graph Structure Learning
CMPE 255 Short-Story Project

This repository contains all deliverables for my **CMPE 255 – Data Mining** short-story research project.  
The project is based on the 2025 survey:

**“A Comprehensive Survey on Spectral Clustering with Graph Structure Learning”**  
[*arXiv:2501.13597v2*](https://arxiv.org/html/2501.13597v2)

The goal of this project is to translate the survey’s technical content into a clear, accessible article and presentation supported by visual diagrams, slides, and a narrated video.

---

##  Project Overview

Spectral clustering is one of the most powerful graph-based clustering methods in modern machine learning.  
This project explores the survey’s central thesis:

> **The quality of spectral clustering fundamentally depends on the quality of the similarity graph.**

Through this work, I explain:

- Pairwise graph construction  
- Adaptive neighbor learning  
- Self-expressive graph models  
- Anchor graph scalability  
- Hypergraph-based high-order learning  
- One-step vs two-step spectral clustering  
- Single-view vs multi-view spectral clustering  
- Future research directions  

The repository provides user-friendly explanations through a **Medium article**, **slide deck**, and a **13 minute video presentation**.
